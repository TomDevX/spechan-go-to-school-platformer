# My first Godot platformer game!

This is my first platformer game made with Godot Engine. It is about [Special Week](https://umamusume.fandom.com/wiki/Special_Week) (a.k.a Spe chan) - my favorite Uma Musume character going to school through the obstacles. To win you need to go to the end of the platform where there are a lots of Spe chan images (and sadly there's no celebrating pop ups, just enjoy the process)

## Keybinds
- Move using arrow keys or W/A/S/D
- Jump = `Space`

## How to run locally?
1. Clone the repo to your computer

```bash
git clone https://github.com/TomDevX/spechan-go-to-school-platformer.git
```

2. Open the project folder with [Godot Engine](https://godotengine.org/)
3. Run the game in Godot and enjoy!
